🎮 Tic Tac Toe Game – Java Swing Project
📌 Overview

This project is a modern Tic Tac Toe Game developed using Java Swing for the graphical user interface. It is a two-player desktop game where players take turns marking X and O on a 3×3 grid. The game automatically detects winning combinations, highlights the winning cells, handles draw situations, and allows players to restart the game instantly.

The application demonstrates core concepts of Java GUI development, event handling, object-oriented programming, and game logic implementation in a simple yet interactive way.

✨ Features
🎯 Interactive 3×3 Tic Tac Toe board
👥 Two-player gameplay (Player X vs Player O)
🏆 Automatic winner detection
🌟 Winning combination highlighting
🤝 Draw condition handling
🔄 Restart game functionality
🎨 Attractive GUI using Java Swing
⚡ Real-time status updates for players
🛠️ Technologies Used
Java
Java Swing

🚀 How to Run
Install Java JDK (8 or above)
Save the file as TicTacToe1.java
Open terminal/command prompt in the project folder
Compile the program:
javac TicTacToe1.java
Run the program:
java TicTacToe1
